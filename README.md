# Q-PRISM

Демо-система для работы с наблюдениями цен на социально значимые продовольственные товары в Кызылорде. Интерфейс доступен на русском и казахском языках; основной шрифт — Inter.

## Возможности демо

- Раздельные рабочие экраны координатора, аналитика, инспектора и жителя.
- Интерактивная карта OpenStreetMap с пятью демонстрационными районами: Орталық, Арай, Мерей, Титов и Тасбөгет.
- Синтетическая 30-дневная выборка по 10 товарам и 5 районам для недельного и месячного обзора.
- Сравнение выбранного района со средней ценой по городу, расчёт самой выгодной корзины и ориентировочный прогноз на 7 дней по тренду последних 14 дней.
- Назначение задач демо-инспекторам, смена статуса и фиксация результата выезда.
- Загрузка фото ценника, тестовый сценарий сканирования и ручное подтверждение данных. Распознавание в этой версии демонстрационное и не использует OCR-модель.
- Загрузка CSV/TSV/XLSX, просмотр, исправление и очистка данных в браузере.
- Скачивание PDF- и CSV-отчётов.

Все цены, районы и наблюдения в комплекте — синтетические демонстрационные данные, не официальная статистика и не реальные подтверждённые торговые точки. Геометки районов ориентировочные. Карта требует подключения к интернету для загрузки тайлов OpenStreetMap. Изменения рабочего сеанса хранятся в памяти вкладки.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```
